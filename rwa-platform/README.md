# RWA 信息平台

一个专业的实体资产代币化（RWA）信息平台，基于 React + Next.js + TailwindCSS + shadcn/ui 构建。

## 🚀 功能特性

### 📊 资产详情页（AssetPage）
- **基本信息展示**：RWA token 名称、符号、法域、清算方式、托管人
- **价格分析**：链上价格 vs 链下价格、预言机源、折溢价分析
- **链上数据**：总供应量、铸造地址、功能支持（赎回/投票/分红）
- **历史价格图表**：基于 Recharts 的交互式价格走势图
- **操作功能**：资产收藏、生成专业分析报告

### 👤 用户资产页（UserPage）
- **钱包连接**：支持以太坊钱包连接
- **资产组合**：显示持仓的 RWA token 列表
- **投资分析**：当前持仓、买入均价、当前市值、盈亏计算
- **AI 智能提醒**：
  - 浮亏超20%预警
  - 可赎回套利窗口提醒
  - 分红通知等

### 🔍 资产浏览/搜索页（BrowsePage）
- **智能搜索**：支持模糊匹配资产名、类型、法域
- **多维度筛选**：
  - 资产类型（债券、股票、黄金、房地产等）
  - 支持链（Ethereum/Base/Polygon/Arbitrum）
  - 赎回模式（自动/手动/不支持）
  - 预言机稳定性（高/中/低）
  - 功能特性（赎回/杠杆/抵押支持）
- **卡片式展示**：清晰展示价格、交易量、功能特性
- **一键跳转**：点击任意资产跳转详情页

## 🛠 技术栈

- **框架**：Next.js 15.4.3 (App Router)
- **开发语言**：TypeScript
- **样式方案**：TailwindCSS + shadcn/ui
- **图表库**：Recharts
- **图标库**：Lucide React
- **状态管理**：React Hooks
- **构建工具**：Next.js + Turbopack

## 🚀 快速开始

```bash

```

### 启动开发服务器
```bash
npm run dev
```

应用将在 http://localhost:3000 启动

### 构建生产版本
```bash
npm run build
```

## 🔧 主要组件说明

### AssetPage
资产详情页，提供完整的资产信息展示和分析功能。

### UserPage  
用户资产页，展示个人投资组合和 AI 智能提醒。

### BrowsePage
资产浏览页，提供强大的搜索和筛选功能。

智能提醒系统，基于用户持仓和市场数据提供个性化建议。

基于 Recharts 的价格图表组件，支持链上链下价格对比。
